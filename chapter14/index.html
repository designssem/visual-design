14차시: 브랜드 가이드북 통합 편집

⏰ 50분 · 브랜드 가이드북 · 페이지 편집 · PDF 출력 · 난이도 ●●●○○

학습목표: 기본시스템과 응용시스템을 하나의 브랜드 가이드북으로 통합 편집하고, 발표용 PDF로 출력할 수 있습니다.

오늘의 질문: “내가 만든 브랜드를 단 한 권의 책으로 보여준다면, 어떤 순서로 펼쳐 보이고 싶나요?”

학습 목표

섹션 제목: “학습 목표”
  • 기본시스템과 응용시스템을 하나의 문서로 엮을 수 있습니다
  • 브랜드 스토리를 시각적으로 전달하는 편집 감각을 키울 수 있습니다
  • 발표용 최종 결과물을 PDF로 정리할 수 있습니다

🤔 왜 이걸 배우나요?

섹션 제목: “🤔 왜 이걸 배우나요?”

여러분이 지금까지 만든 로고, 컬러, 타이포그래피, 명함, 굿즈, 포스터… 이 모든 조각들은 각자 예쁘지만 따로따로 흩어져 있으면 브랜드로 보이지 않습니다. 마치 맛있는 재료를 냉장고에 넣어두기만 한 것과 같죠. 브랜드 가이드북은 이 재료들을 한 권의 요리책으로 엮는 작업입니다.

스타벅스, 애플, 배달의민족 같은 브랜드가 전 세계 어디서나 똑같이 보이는 이유는, 누구나 펼쳐볼 수 있는 브랜드 가이드북이 있기 때문입니다. 오늘은 여러분이 직접 그 책의 저자가 됩니다.

🎯 오늘의 핵심 주제

섹션 제목: “🎯 오늘의 핵심 주제”

🧠 가이드북 구조

섹션 제목: “🧠 가이드북 구조”

표지부터 마무리까지, 브랜드를 보여주는 페이지 순서를 설계합니다.

🎨 통합 편집

섹션 제목: “🎨 통합 편집”

흩어진 시스템을 하나의 톤으로 엮어 완성도 있는 책으로 만듭니다.

발표용 최종본과 썸네일을 함께 준비하여 공유 가능한 결과물로 완성합니다.

실제 브랜드 가이드북 예시를 보며 구조를 파악합니다.

📚 Step 1: 가이드북이란 무엇인가 (8분)

섹션 제목: “📚 Step 1: 가이드북이란 무엇인가 (8분)”

🎬 가이드북은 ‘브랜드의 사용 설명서’

섹션 제목: “🎬 가이드북은 ‘브랜드의 사용 설명서’”

여러분이 새 스마트폰을 샀을 때 따라오는 사용 설명서를 떠올려 보세요. “이 버튼은 이렇게 누르세요”, “충전은 이 방법으로 하세요”처럼 정해진 규칙이 적혀 있죠.

브랜드 가이드북도 똑같습니다. “우리 로고는 이렇게 써주세요”, “우리 컬러는 이 코드값만 쓰세요”, “명함은 이 레이아웃으로 만드세요”라고 브랜드 사용법을 친절하게 안내하는 책입니다.

📖 가이드북의 표준 구조

섹션 제목: “📖 가이드북의 표준 구조”

아래는 실제 기업 가이드북이 공통으로 갖는 구조입니다.

섹션페이지담는 내용목적
표지1p브랜드명, 로고, 발행일첫인상, 누구의 책인가
브랜드 소개2-3p브랜드 스토리, 슬로건, 타깃”우리는 누구인가”
기본 시스템4-7p로고, 컬러, 타이포브랜드 DNA
응용 시스템8-11p명함, 굿즈, 포스터실제 적용 사례
금지 규정12p하면 안 되는 사용 예시일관성 유지
마무리13p제작자, 연락처, 감사 인사엔딩 크레딧
flowchart LR
  A[표지] --> B[브랜드<br/>소개]
  B --> C[기본<br/>시스템]
  C --> D[응용<br/>시스템]
  D --> E[금지<br/>규정]
  E --> F[마무리]

위 흐름은 “누구인지 → 어떻게 생겼는지 → 어떻게 쓰는지 → 하면 안 되는 것” 순서입니다. 읽는 사람이 브랜드를 자연스럽게 이해할 수 있도록 이야기처럼 배치하는 것이 핵심입니다.

📚 Step 2: 내 가이드북 페이지 설계 (10분)

✏️ 페이지 기획서 작성

섹션 제목: “✏️ 페이지 기획서 작성”

본격적인 편집 전에, 어떤 페이지를 몇 장에 넣을지 먼저 종이에 계획합니다. 건축가가 집을 짓기 전에 설계도를 그리는 것과 같습니다.

아래 표를 워크시트로 사용하여 내 가이드북 목차를 채워보세요.

페이지섹션명들어갈 자료중심 메시지 (한 줄)
1p표지
2p브랜드 소개
3p로고 시스템
4p컬러 시스템
5p타이포그래피
6p응용 1 (명함)
7p응용 2 (굿즈)
8p응용 3 (포스터)
9p금지 규정
10p마무리

💡 페이지 순서 설계 팁

섹션 제목: “💡 페이지 순서 설계 팁”
  • 표지는 로고만 크게. 설명은 최소화하세요. “이게 누구의 가이드북인가”만 보이면 됩니다.
  • 브랜드 소개는 스토리 중심. “왜 이 브랜드를 만들었나”가 핵심입니다.
  • 기본시스템 → 응용시스템 순서를 반드시 지키세요. 규칙을 먼저 보여주고, 적용 예시를 뒤에 보여야 설득력이 생깁니다.
  • 한 페이지 = 한 주제 원칙. 한 페이지에 로고와 컬러를 다 넣지 마세요. 숨 쉴 공간이 필요합니다.

선생님 한마디 “페이지 수가 꼭 10장이어야 할 필요는 없습니다. 8장이든 12장이든, 여러분의 브랜드를 가장 잘 보여줄 수 있는 구성이면 충분합니다.”

📐 편집 5단계 따라하기

섹션 제목: “📐 편집 5단계 따라하기”

1단계: 페이지 규격 통일 (3분)

섹션 제목: “1단계: 페이지 규격 통일 (3분)”

모든 페이지를 같은 비율로 맞춥니다. 가장 많이 쓰는 규격은 다음과 같습니다.

  • A4 세로 (210 x 297mm): 인쇄용 정식 문서 느낌
  • 16:9 가로 (1920 x 1080px): 발표용 슬라이드 느낌

💡 세로와 가로를 섞으면 PDF에서 방향이 뒤죽박죽이 됩니다. 하나로 통일하세요.

2단계: 마스터 레이아웃 만들기 (4분)

섹션 제목: “2단계: 마스터 레이아웃 만들기 (4분)”

모든 페이지에 공통으로 들어가는 요소를 정합니다.

위치공통 요소
상단 좌측작은 로고 또는 브랜드명
상단 우측섹션명 (예: “COLOR SYSTEM”)
하단 중앙 또는 우측페이지 번호
여백 (margin)상하좌우 최소 2cm

마스터 레이아웃이 있으면 “아, 이 책이 하나로 이어지는구나”라는 느낌을 줍니다. 페이지마다 로고 위치가 달라지면 통일성이 깨집니다.

3단계: 자료 배치 (10분)

섹션 제목: “3단계: 자료 배치 (10분)”

지금까지 만든 자료를 순서대로 붙여넣습니다. 이때 3가지 원칙을 지키세요.

  • 여백을 두려워하지 마세요. 빈 공간이 있어야 주인공이 돋보입니다.
  • 컬러는 브랜드 팔레트에서만. 설명 글자색까지 브랜드 컬러로 맞추면 완성도가 확 올라갑니다.
  • 폰트는 2종류 이내. 제목용 1개, 본문용 1개면 충분합니다.

4단계: 페이지 간 톤 맞추기 (3분)

섹션 제목: “4단계: 페이지 간 톤 맞추기 (3분)”

각 페이지를 쭉 넘기면서 이질감이 드는 페이지를 찾아 수정합니다.

  • 폰트 크기가 페이지마다 다르지 않은가?
  • 배경색이 갑자기 튀지는 않는가?
  • 이미지 해상도가 낮아 깨지는 페이지는 없는가?
  • 제목 위치가 페이지마다 어긋나지 않는가?

5단계: 금지 규정 페이지 만들기 (2분)

섹션 제목: “5단계: 금지 규정 페이지 만들기 (2분)”

마지막으로 “이렇게 쓰면 안 됩니다” 페이지를 추가합니다. X 표시와 함께 잘못된 예시를 보여주면 가이드북의 완성도가 크게 올라갑니다.

금지 예시이유
로고 색상 임의 변경브랜드 인식 방해
로고 찌그러뜨리기비례 왜곡
저채도 배경 위에 저채도 로고가독성 저하
타 브랜드 폰트로 대체톤 불일치

📚 Step 4: PDF 출력 & 썸네일 제작 (10분)

객관식 1. 브랜드 가이드북의 페이지 순서로 가장 적절한 것은?

① 표지 → 응용시스템 → 기본시스템 → 마무리 ② 표지 → 브랜드 소개 → 기본시스템 → 응용시스템 → 마무리 ③ 브랜드 소개 → 표지 → 응용시스템 → 금지 규정 ④ 기본시스템 → 표지 → 브랜드 소개 → 응용시스템

정답 확인

정답: ②

가이드북은 “누구인지(소개) → 어떻게 생겼는지(기본시스템) → 어떻게 쓰는지(응용시스템)” 순서로 전개되어야 읽는 사람이 자연스럽게 브랜드를 이해할 수 있습니다.

객관식 2. 가이드북 통합 편집 시 통일성을 만들기 위해 가장 먼저 해야 할 일은?

① 페이지에 이미지를 많이 넣는다 ② 모든 페이지를 같은 규격과 마스터 레이아웃으로 맞춘다 ③ 페이지마다 다른 폰트를 사용해 다양성을 준다 ④ 표지를 가장 화려하게 꾸민다

정답 확인

정답: ②

페이지 규격과 마스터 레이아웃(로고 위치, 섹션명, 페이지 번호 등)을 먼저 통일해야 책 전체가 하나로 이어진 느낌을 줍니다. 폰트·컬러 통일은 그 다음 단계입니다.

객관식 3. 금지 규정 페이지에 들어갈 내용으로 가장 적절한 것은?

① 브랜드의 역사와 스토리 ② 로고를 잘못 사용한 예시와 그 이유 ③ 디자이너의 개인 포트폴리오 ④ 경쟁사 브랜드 소개

정답 확인

정답: ②

금지 규정(Don’ts)은 로고 색상 변경, 비례 왜곡, 저가독성 배치 등 하면 안 되는 사용 예시를 보여주어 브랜드 일관성을 지키는 역할을 합니다.

✍️ 서술형

섹션 제목: “✍️ 서술형”

서술형 1. 내 브랜드 가이드북 표지에 어떤 요소를 넣을지, 그리고 그렇게 정한 이유를 3-5줄로 써보세요.

예시 답안

예시: “나의 카페 브랜드 ‘달빛’ 표지에는 로고와 브랜드명만 크게 넣고 배경은 진한 남색으로 채웠습니다. 표지에 너무 많은 정보를 담으면 주인공인 로고가 묻히기 때문에, 첫인상은 브랜드의 얼굴(로고)만 보여주는 것이 강렬하다고 판단했습니다. 발행일은 하단에 작게 넣어 정식 문서 느낌을 살렸습니다.”

✅ 자기점검 체크리스트

섹션 제목: “✅ 자기점검 체크리스트”
