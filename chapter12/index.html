    12차시: 자유 응용물 제작 ① - 레이아웃과 시안¶

    ⏰ 50분 · 레이아웃 · 시안 제작 · 매체 특성 · 기본시스템 변형 · 난이도 ●●●○○

    학습목표: 선택한 응용물의 레이아웃을 구성하고, 기본시스템을 매체 특성에 맞게 적용한 1차 시안을 완성할 수 있다.

    오늘의 질문: "같은 로고인데, 왜 명함에서는 멋져 보이고 인스타그램에서는 뭉개져 보일까요?"

    🤔 왜 이걸 배우나요?¶

    11차시까지 우리는 브랜드의 기본시스템(로고, 컬러, 타이포)을 완성했습니다. 하지만 기본시스템은 '재료'일 뿐입니다. 실제로 세상에 나가려면 명함, 포스터, 패키지, SNS 게시물 같은 '요리'로 만들어져야 합니다.

    문제는 같은 재료라도 요리마다 조리법이 다르다는 점입니다. 명함은 손에 쥐고 가까이 보지만, 간판은 10미터 밖에서 봅니다. 인스타그램 프로필은 지름 3cm의 동그라미 안에 들어가야 합니다. 매체가 다르면 로고의 크기, 여백, 배치가 모두 달라져야 합니다.

    오늘은 여러분이 선택한 응용물에 브랜드를 어떻게 '요리'할지 결정하고, 1차 시안을 만들어봅니다.

    🎯 오늘의 핵심 주제¶

    🧠 레이아웃 그리드¶

    요소를 질서 있게 배치하기 위한 보이지 않는 뼈대

    🔄 매체별 변형 원칙¶

    기본시스템을 매체 크기·용도에 맞게 재배치하는 규칙

    🎨 1차 시안 제작¶

    규격 설정 → 그리드 → 요소 배치 → 자가 점검

    💬 동료 피드백¶

    짝과 시안을 교환해 수정 포인트 도출

    ⏱️ 수업 흐름¶

    도입: 같은 로고, 다른 얼굴 (7분)¶

    브랜드가 매체에 따라 어떻게 변형되는지 실제 사례로 관찰합니다.

    개념 학습: 그리드와 매체별 원칙 (13분)¶

    레이아웃 그리드와 매체별 변형 원칙을 익힙니다.

    실습: 1차 시안 제작 (22분)¶

    규격을 설정하고, 그리드 위에 기본시스템을 배치합니다.

    정리: 자가 점검 & 동료 피드백 (8분)¶

    체크리스트로 점검하고 짝과 시안을 교환해 피드백을 주고받습니다.

    📚 Step 1. 도입 — 같은 로고, 다른 얼굴 (7분)¶

    관찰 활동: 스타벅스는 어떻게 변신하나요?¶

    여러분이 아는 스타벅스 로고를 떠올려보세요. 그런데 이 로고는 장소마다 조금씩 다르게 등장합니다.

    매체 로고 형태 여백 왜 이렇게?
    종이컵 원형 엠블럼 전체 여백 많음 손으로 쥐었을 때 가려지지 않게
    매장 간판 원형 엠블럼 크게 여백 적음 멀리서도 인식되어야 함
    인스타그램 프로필 세이렌 얼굴만 확대 없음 지름 3cm 원 안에 들어가야 함
    앱 아이콘 세이렌 얼굴 + 녹색 배경 사각형 모서리 둥근 사각형 규격
    영수증 단색 텍스트 로고 한 줄 감열지 인쇄 한계

    핵심 통찰: 브랜드는 '고정된 그림'이 아니라 '상황에 적응하는 시스템'입니다. 매체의 크기, 거리, 인쇄 방식에 따라 같은 로고도 다른 옷을 입습니다.

    생각해보기¶

    • 내가 만든 브랜드의 로고를 인스타그램 프로필(원형, 320x320px)에 넣는다면, 원본 그대로 넣어도 알아볼 수 있을까요?
    • 명함(9x5cm)에 넣는 로고와 포스터(A2)에 넣는 로고는 어떻게 달라야 할까요?

    📚 Step 2. 개념 학습 — 그리드와 매체별 원칙 (13분)¶

    핵심 개념 ① 레이아웃 그리드¶

    비유: 그리드는 '보이지 않는 모눈종이'입니다. 완성된 디자인에는 선이 보이지 않지만, 디자이너는 이 선을 기준으로 모든 요소를 배치합니다. 신문이 깔끔해 보이는 이유, 잡지가 정돈되어 보이는 이유가 바로 그리드 때문입니다.

    정의: 레이아웃 그리드는 페이지를 일정한 칸과 여백으로 나누어, 요소들이 시각적 질서를 갖고 배치되도록 돕는 구조입니다.

    그리드의 3요소¶

    flowchart LR A[마진<br/>외곽 여백] --> D[그리드 시스템] B[컬럼<br/>세로 칸] --> D C[거터<br/>칸 사이 간격] --> D D --> E[시각적 질서]
    요소 역할 실생활 비유
    마진(Margin) 페이지 바깥쪽 여백 액자의 프레임
    컬럼(Column) 내용이 들어가는 세로 칸 책장의 칸막이
    거터(Gutter) 컬럼과 컬럼 사이 간격 책장 사이의 통로

    매체별 추천 그리드¶

    매체 권장 컬럼 마진 특징
    명함 (9x5cm) 2-3 컬럼 3-5mm 작으므로 요소 2-3개만
    포스터 (A2) 6-12 컬럼 15-25mm 위계가 명확해야 함
    SNS 정사각형 (1080x1080) 3x3 그리드 80-100px 중앙 정렬 선호
    패키지 전개도 면마다 별도 안전영역 5mm 접히는 선 주의

    핵심 개념 ② 매체별 변형 원칙¶

    기본시스템을 매체에 적용할 때 지켜야 할 4가지 원칙입니다.

    원칙 1: 최소 크기 원칙¶

    로고에는 "이보다 작아지면 안 되는 최소 크기"가 있습니다. 예를 들어 가로 로고는 보통 20mm, 심볼은 10mm 이하로 줄이지 않습니다. 작아지면 디테일이 뭉개지기 때문입니다.

    Tip: 작은 매체(파비콘, SNS 프로필)에서는 심볼만 사용하세요. 워드마크(글자 로고)는 가독성을 잃습니다.

    원칙 2: 보호 영역(Clear Space) 원칙¶

    로고 주변에는 '개인 공간'이 필요합니다. 다른 요소가 이 영역에 침범하면 로고가 답답해 보입니다. 보통 로고 높이의 1/2 이상을 비워둡니다.

    원칙 3: 컬러 대비 원칙¶

    배경 색상에 따라 로고 색상을 바꿔야 합니다. 밝은 배경에는 원본, 어두운 배경에는 반전(네거티브) 버전을 사용합니다.

    배경 로고 버전
    흰색/밝은색 원본 컬러
    브랜드 메인 컬러 화이트/블랙
    어두운 배경 화이트 네거티브
    사진/복잡한 배경 단색 + 반투명 박스

    원칙 4: 시각적 위계 원칙¶

    한 화면에 모든 것을 똑같이 크게 넣으면 아무것도 안 보입니다. 가장 중요한 것 → 두 번째 → 세 번째 순으로 크기와 굵기를 다르게 합니다.

    flowchart TD A[1순위: 주목 요소<br/>가장 큼, 가장 강함] --> B[2순위: 핵심 정보<br/>중간 크기] B --> C[3순위: 보조 정보<br/>작고 연함]

    예시 (포스터의 경우): - 1순위: 이벤트 제목 또는 메인 이미지 - 2순위: 날짜·장소 - 3순위: 로고, 주최자, 문의처

    📚 Step 3. 실습 — 1차 시안 제작 (22분)¶

    오늘 만들 응용물 선택 확인¶

    11차시에서 선택한 응용물 중 1개를 오늘 시안으로 만듭니다. (예: 명함 / 포스터 / SNS 게시물 / 패키지 / 간판)

    제작 순서¶

    flowchart LR A[1. 규격 설정] --> B[2. 그리드 구축] B --> C[3. 요소 배치] C --> D[4. 컬러·타이포 적용] D --> E[5. 자가 점검]

    단계 1: 규격 설정 (3분)¶

    아트보드(작업 화면) 크기를 정확히 설정합니다.

    응용물 표준 규격 해상도
    명함 90 x 50 mm 300 dpi (인쇄)
    A4 포스터 210 x 297 mm 300 dpi
    인스타그램 정사각 1080 x 1080 px 72 dpi (화면)
    인스타그램 스토리 1080 x 1920 px 72 dpi
    유튜브 썸네일 1280 x 720 px 72 dpi
    패키지(박스 전개도) 실측 후 전개 300 dpi

    ⚠️ 주의: 인쇄물은 재단여백(Bleed) 3mm를 추가해서 만드세요. (명함이면 96x56mm로 작업)

    단계 2: 그리드 구축 (3분)¶

    선택한 매체에 맞는 그리드를 설정합니다.

    실습 워크시트

    항목 내 응용물에 적용
    매체 이름
    전체 크기
    마진 (상·하·좌·우)
    컬럼 개수
    거터 크기

    단계 3: 요소 배치 (8분)¶

    그리드 위에 어떤 요소를 어디에 놓을지 러프 스케치부터 합니다. 바로 화면에 그리지 말고, 종이에 엄지손톱만 한 썸네일 스케치를 3-5개 그려본 후 가장 좋은 것을 선택하세요.

    배치 체크리스트

    • 로고의 위치와 크기를 결정했나요? (최소 크기 이상인가요?)
    • 로고 주변에 보호 영역을 확보했나요?
    • 가장 중요한 정보가 가장 크게 표현되었나요?
    • 요소들이 그리드 라인에 정렬되어 있나요?
    • 여백이 충분해서 답답하지 않은가요?

    단계 4: 컬러·타이포 적용 (6분)¶

    기본시스템에서 정한 컬러 팔레트와 지정 서체를 적용합니다.

    컬러 적용 원칙 - 메인 컬러는 한 곳에 포인트로 (전체 면적의 20-30%) - 배경은 화이트 또는 연한 서브 컬러 - 텍스트는 가독성 확보 (배경 대비 충분히)

    타이포 적용 원칙 - 지정 서체(헤드라인용/본문용) 외에는 쓰지 않기 - 크기 단계는 3-4개로 제한 (예: 24pt / 14pt / 10pt) - 한 줄 길이는 너무 길지 않게 (한글 기준 15-25자)

    단계 5: 자가 점검 (2분)¶

    아래 표로 1차 시안을 스스로 점검합니다.

    점검 항목 O/X 메모
    로고가 원칙(최소 크기·보호 영역)을 지키고 있는가
    브랜드 컬러가 정확히 사용되었는가
    지정 서체만 사용되었는가
    시각적 위계가 명확한가
    그리드에 정렬되어 있는가
    매체 특성(크기·보는 거리)을 고려했는가

    🤝 Step 4. 정리 — 동료 피드백 (8분)¶

    짝과 시안 교환하기 (5분)¶

    짝에게 내 시안을 보여주며 아래 3가지를 물어보세요. 그리고 짝의 시안에 대해서도 같은 질문에 답해주세요.

    피드백 3질문

    질문 짝의 답변 기록
    ① 이 시안에서 가장 먼저 눈에 들어오는 것은 무엇인가요?
    ② 어떤 브랜드 느낌이 드나요? (3개 형용사로)
    ③ 수정하면 더 좋아질 부분은 어디일까요?

    ① 답이 '내가 의도한 것'과 다르다면 → 시각적 위계를 다시 점검 ② 답이 브랜드 콘셉트와 다르다면 → 컬러·서체·이미지 선택 재검토 ③ 답을 그대로 반영하지 말고, '왜 그런 피드백이 나왔을까' 생각하세요

    수정 포인트 정리 (3분)¶

    자가 점검 + 동료 피드백을 종합해 다음 차시에 수정할 3가지를 기록합니다.

    우선순위 수정할 내용 수정 이유
    1순위
    2순위
    3순위

    ⚠️ 자주 하는 실수¶

    실수 해결책
    로고를 너무 크게 넣기 로고는 "어디 브랜드인지 알려주는" 역할. 주인공은 메시지·이미지
    여백 없이 가득 채우기 여백은 버리는 공간이 아니라 '숨 쉬는 공간'
    서체를 3종 이상 섞기 지정 서체만 사용, 크기와 굵기로 변화 주기
    그리드 무시하고 자유 배치 디자인은 '정돈된 자유', 기준선 없이는 산만해짐
    화면에서만 확인하기 인쇄물은 반드시 실제 크기로 출력해 손에 쥐고 확인

    📝 평가¶

    📝 형성 평가¶

    객관식 1. 로고의 '보호 영역(Clear Space)'에 대한 설명으로 옳은 것은?

    ① 로고를 인쇄할 때 사용하는 특수 필름의 이름이다 ② 로고 주변에 다른 요소가 침범하지 못하도록 확보하는 여백이다 ③ 로고 파일을 저장하는 컴퓨터 폴더 이름이다 ④ 로고에 사용되는 저작권 보호 구역이다

    정답 확인 **정답: ②** 보호 영역은 로고 주변에 확보하는 최소 여백으로, 다른 요소가 침범해 로고의 인식을 방해하지 않도록 하는 규칙입니다.

    객관식 2. 인스타그램 프로필 이미지(지름 약 3cm 원형)에 적용할 로고로 가장 적절한 것은?

    ① 가로로 긴 워드마크 전체 ② 영문 풀네임 + 심볼 조합 ③ 심볼만 분리해 사용한 단순 버전 ④ 슬로건까지 포함한 전체 로고

    정답 확인 **정답: ③** 작은 매체에서는 디테일이 뭉개지므로, 심볼만 분리한 단순 버전을 사용해야 인식력이 유지됩니다. (최소 크기 원칙)

    객관식 3. 레이아웃 그리드의 '거터(Gutter)'가 의미하는 것은?

    ① 페이지 바깥 여백 ② 컬럼과 컬럼 사이의 간격 ③ 로고의 최소 크기 ④ 인쇄 시 재단되는 영역

    정답 확인 **정답: ②** 거터는 컬럼 사이의 간격으로, 내용이 서로 붙어 보이지 않도록 분리하는 역할을 합니다. ①은 마진, ④는 블리드(Bleed)입니다.

    서술형. 내가 오늘 제작한 응용물에 기본시스템(로고·컬러·타이포)을 어떻게 변형해 적용했는지, 매체 특성과 연결하여 3-4문장으로 설명하세요.

    답안 예시 예시: "저는 카페 브랜드의 인스타그램 정사각형 게시물을 제작했습니다. 화면이 작고 스크롤하며 보는 매체이므로, 로고는 심볼만 사용하고 오른쪽 하단에 작게 배치했습니다. 메인 컬러인 연한 베이지를 배경 전체에 깔아 브랜드 톤을 느끼게 했고, 헤드라인 서체를 크게 써서 2-3초 안에 메시지가 읽히도록 했습니다."

    ✅ 자기점검 체크리스트¶

    • 선택한 응용물의 정확한 규격으로 아트보드를 설정했다
    • 레이아웃 그리드(- [ ] 선택한 응용물의 정확한 규격으로 아트보드를 설정했다
    • 레이아웃 그리드(마진·컬럼·거터)를 구축했다
    • 기본시스템(로고·컬러·타이포)을 매체 특성에 맞게 변형해 적용했다
    • 시각적 위계가 명확한 1차 시안을 완성했다
    • 자가 점검과 동료 피드백을 통해 수정 포인트 3가지를 도출했다

    오늘 배운 것을 한 문장으로¶

    "브랜드는 고정된 그림이 아니라, 매체에 맞춰 옷을 갈아입는 시스템이다."

    같은 로고라도 명함에서는 작게, 포스터에서는 크게, 인스타에서는 심볼만으로 등장합니다. 이 모든 변형을 관통하는 것은 기본시스템의 원칙입니다. 원칙을 지키되 매체에 적응하는 것, 이것이 응용 시스템 디자인의 핵심입니다.

    🎒 오늘의 과제 (선택)¶

    시간이 남는다면 오늘 만든 시안을 실제 크기로 종이에 출력해 손에 쥐고 확인해보세요. 화면으로 볼 때와 실제로 들었을 때의 느낌은 놀랄 만큼 다릅니다. 이때 발견한 어색함은 다음 차시 수정 1순위가 됩니다.

    💡 디자이너의 팁: 좋은 디자이너는 '완벽한 첫 시안'을 만드는 사람이 아니라, '피드백을 잘 받아들이는 사람'입니다. 오늘 만든 시안이 마음에 들지 않아도 괜찮습니다. 수정할 부분을 3개나 찾아냈다는 것이 오히려 큰 성장입니다.
