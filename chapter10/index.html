    10차시: 명함 디자인 실습 (필수 응용물)¶

    ⏰ 50분 · 명함규격 · 재단선 · 레이아웃 · 인쇄용PDF · 난이도 ●●●○○

    학습목표: 기본시스템을 적용하여 앞뒷면이 통일된 명함 시안을 완성하고 인쇄용 PDF로 내보낼 수 있다.

    오늘의 질문: "손바닥만 한 종이 한 장에, 나의 브랜드를 어떻게 담을 수 있을까요?"

    🤔 왜 이걸 배우나요?¶

    여러분이 처음 만나는 사람에게 자신을 소개할 때, 몇 초 만에 이름과 직업, 연락처를 전달해야 한다면 어떻게 할까요? 명함은 바로 그 역할을 합니다. 손에 쥘 수 있는 가장 작은 브랜딩 매체죠.

    스타벅스 바리스타의 명함, 애플 직원의 명함, 동네 빵집 사장님의 명함. 모두 같은 90×50mm 크기지만, 각자 다른 브랜드의 '인상'을 전달합니다. 명함은 단순한 연락처 카드가 아니라, 브랜드의 첫인상을 손에 남기는 미니 포스터입니다.

    9차시까지 여러분은 로고, 컬러, 타이포그래피로 구성된 '기본시스템'을 만들었습니다. 이제 그 시스템을 실제 제작물에 적용하는 첫 실습입니다. 명함이 잘 만들어지면, 포스터도 쇼핑백도 간판도 같은 원리로 펼쳐집니다.

    🎯 오늘의 핵심 주제¶

    🧠 명함의 규격과 인쇄 사양¶

    90×50mm, 재단선·안전선·여백의 개념을 이해합니다.

    ✂️ 기본시스템 적용 레이아웃¶

    로고·정보·컬러를 앞뒷면에 배치하는 원리를 익힙니다.

    🖨️ 인쇄용 PDF 내보내기¶

    CMYK·재단선 포함 PDF로 실제 인쇄 가능한 파일을 만듭니다.

    ⏱️ 수업 흐름¶

    1. 도입: 명함 분석하기 (8분)¶

    실제 명함 사례를 관찰하며 레이아웃 공통점을 찾습니다.

    2. 핵심 개념: 규격과 재단선 (10분)¶

    90×50mm, 재단선 3mm, 안전선 5mm의 원리를 학습합니다.

    3. 따라하기: 앞면 시안 제작 (17분)¶

    Illustrator에서 아트보드 설정 후 앞면을 완성합니다.

    4. 따라하기: 뒷면 + PDF 내보내기 (12분)¶

    뒷면 시안 제작 후 인쇄용 PDF로 저장합니다.

    5. 마무리: 상호 피드백 & 성찰 (3분)¶

    짝과 시안을 교환하여 피드백을 나눕니다.

    📚 핵심 개념 1: 명함의 규격과 인쇄 사양¶

    🍱 도시락 뚜껑처럼 딱 맞는 표준 크기¶

    도시락 통을 살 때 내용물보다 뚜껑이 약간 큰 이유는 뭘까요? 여닫을 때 여유가 필요하기 때문입니다. 명함도 마찬가지예요. 인쇄소에서 종이를 자를 때 칼선이 1mm만 밀려도 디자인이 잘려 나가거나 흰 여백이 생깁니다. 그래서 디자이너는 '잘릴 수 있는 여유'와 '절대 잘리면 안 되는 안전 구역'을 미리 정해두고 작업합니다.

    📐 세 가지 선의 정의¶

    구분 크기 역할
    작업 크기(도련 포함) 96×56mm 인쇄소에 넘기는 실제 파일 크기
    재단선(완성 크기) 90×50mm 최종적으로 잘리는 명함의 크기
    안전선 80×40mm 글자·로고가 반드시 이 안에 들어와야 하는 영역
    • 도련(Bleed): 재단선 바깥 3mm. 배경 컬러가 여기까지 꽉 차야 칼이 밀려도 흰 선이 안 생깁니다.
    • 안전 여백(Safety Margin): 재단선 안쪽 5mm. 중요한 글자는 이 선 안쪽에만 배치합니다.
    flowchart TB A[작업 크기 96×56mm<br/>배경이 여기까지 채워져야 함] --> B[재단선 90×50mm<br/>실제 잘리는 위치] B --> C[안전선 80×40mm<br/>글자·로고는 이 안에만]

    💡 쉽게 기억하기: "배경은 넉넉하게, 글자는 좁게." 배경 컬러나 이미지는 재단선 밖까지, 중요한 정보는 안전선 안쪽까지.

    🎨 인쇄용 파일의 기본 사양¶

    항목 설정값 이유
    색상 모드 CMYK 인쇄 잉크 기준 (모니터는 RGB)
    해상도 300dpi 이상 인쇄 시 선명도 확보
    폰트 처리 윤곽선 만들기(Outline) 인쇄소에 폰트 없어도 깨지지 않음
    파일 형식 PDF (인쇄용) 재단선·도련 정보 포함 저장

    📚 핵심 개념 2: 기본시스템 적용 레이아웃¶

    🎽 교복처럼 통일된 규칙¶

    학교 교복을 떠올려 보세요. 흰 셔츠, 감색 재킷, 체크 치마. 정해진 규칙 안에서 학생마다 조금씩 다르게 입죠. 명함 앞뒷면도 이와 같아요. 로고 위치, 컬러, 폰트 같은 규칙은 통일하되, 담는 정보만 달라집니다.

    📋 앞면과 뒷면의 역할 분담¶

    면 주 역할 담는 요소
    앞면 개인 정보 전달 이름, 직책, 연락처, 이메일, 주소, 로고
    뒷면 브랜드 각인 로고(크게), 슬로건, 브랜드 컬러 전면

    🧩 앞면 레이아웃의 3가지 기본 유형¶

    flowchart LR A[수평 분할형<br/>로고 왼쪽 / 정보 오른쪽] B[상하 분할형<br/>위 로고 / 아래 정보] C[코너 집중형<br/>한쪽 모서리에 로고]
    • 수평 분할형: 가장 무난하고 전문적. 정보량이 많을 때 적합
    • 상하 분할형: 로고를 크게 강조. 시각적 임팩트
    • 코너 집중형: 여백이 많아 세련된 느낌. 미니멀 브랜드에 적합

    🎯 정보 위계(Hierarchy) 정하기¶

    명함 앞면의 정보는 모두 같은 크기로 넣으면 안 됩니다. 가장 중요한 정보 → 덜 중요한 정보 순으로 크기·굵기를 차등화합니다.

    위계 요소 크기 가이드
    1순위 이름 10-12pt, Bold
    2순위 직책·회사명 7-8pt, Regular
    3순위 연락처·이메일·주소 6-7pt, Regular

    💡 규칙: 명함은 작습니다. 폰트는 최소 6pt 이상으로 해야 읽힙니다. 그 이하는 흐릿하게 인쇄됩니다.

    🖱️ 따라하기 실습¶

    Step 1. Illustrator 아트보드 설정¶

    1. 파일 → 새로 만들기 클릭
    2. 다음 값 입력:
    3. 폭: 96mm, 높이: 56mm (도련 포함 크기)
    4. 아트보드 수: 2개 (앞면·뒷면)
    5. 색상 모드: CMYK
    6. 래스터 효과: 300ppi
    7. 고급 옵션 → 도련(Bleed): 상하좌우 3mm 입력
    8. 만들기 클릭

    → 화면에 아트보드 2개가 생기고, 각 아트보드 바깥에 빨간 도련선이 표시됩니다.

    Step 2. 가이드선 만들기 (안전선)¶

    1. 보기 → 눈금자 → 눈금자 표시 (Ctrl+R)
    2. 왼쪽 눈금자에서 드래그하여 세로 가이드선 생성
    3. 아트보드 왼쪽·오른쪽 가장자리에서 안쪽으로 5mm 지점에 배치
    4. 위쪽 눈금자에서도 동일하게 상하 5mm 지점에 가로 가이드 배치

    → 이 가이드 안쪽이 안전 영역(80×40mm)입니다.

    Step 3. 앞면 디자인 — 요소 배치¶

    1. 로고 배치: 9차시에서 만든 로고를 왼쪽 영역에 배치 (안전선 내부)
    2. 정보 입력 (오른쪽 영역): 
      홍길동
브랜드 디자이너

010-1234-5678
hong@brand.co.kr
서울시 마포구 ○○로 12
    3. 브랜드 기본 서체 적용, 위계에 따라 크기 차등 설정
    4. 브랜드 컬러를 이름 또는 구분선에 포인트로 사용

    Step 4. 뒷면 디자인 — 브랜드 각인¶

    1. 두 번째 아트보드로 이동
    2. 배경 전체를 브랜드 메인 컬러로 채우기 (도련까지 꽉 차게!)
    3. 중앙에 로고를 크게 배치 (흰색 또는 보조 컬러 버전)
    4. 필요 시 슬로건 한 줄 추가

    Step 5. 인쇄용 PDF 내보내기¶

    1. 모든 텍스트 선택 → 문자 → 윤곽선 만들기 (Ctrl+Shift+O)
    2. 파일 → 다른 이름으로 저장 → 형식 Adobe PDF
    3. Adobe PDF 사전 설정: [PDF/X-1a:2001] 선택
    4. 표시 및 도련 탭 → 재단선 표시 체크, 문서 도련 설정 사용 체크
    5. PDF 저장 클릭

    → 파일명: 명함_이름_v1.pdf

    ⚠️ 자주 하는 실수¶

    실수 결과 해결책
    배경 컬러를 재단선까지만 채움 인쇄 후 흰 테두리가 보임 도련선(96×56)까지 꽉 채우기
    글자를 재단선 가까이 배치 글자가 잘리거나 답답해 보임 안전선 안쪽(5mm 여백)에 배치
    RGB 모드로 작업 인쇄 시 색이 칙칙해짐 처음부터 CMYK 설정
    폰트를 윤곽선 처리 안 함 인쇄소에서 폰트 깨짐 저장 전 반드시 Outline 처리
    6pt 미만 작은 글씨 인쇄 시 뭉개져 안 읽힘 최소 6pt 이상 유지

    📝 형성 평가¶

    객관식¶

    1. 명함 작업 시 배경 컬러는 어디까지 채워야 할까요?

    ① 안전선까지 (80×40mm) ② 재단선까지 (90×50mm) ③ 도련 포함 작업 크기까지 (96×56mm) ④ 아트보드 바깥까지 무제한

    정답 확인 **정답: ③** 재단 시 칼이 밀려도 흰 선이 생기지 않도록 도련(3mm)을 포함한 96×56mm까지 배경을 채워야 합니다. 재단선까지만 채우면 인쇄 후 가장자리에 흰 줄이 보일 수 있습니다.

    2. 인쇄용 파일 작업 시 적절하지 않은 설정은?

    ① 색상 모드 CMYK ② 해상도 300dpi ③ 색상 모드 RGB ④ 폰트를 윤곽선(Outline) 처리

    정답 확인 **정답: ③** RGB는 모니터 화면용 색상 모드입니다. 인쇄물은 반드시 CMYK(청록·자홍·노랑·검정) 잉크 기준으로 작업해야 의도한 색상이 나옵니다.

    3. 명함 앞면 정보 중 가장 크게 배치되어야 하는 것은?

    ① 전화번호 ② 이메일 ③ 회사 주소 ④ 이름

    정답 확인 **정답: ④** 정보 위계상 이름이 1순위입니다. 명함은 '내가 누구인지'를 전달하는 매체이므로 이름이 가장 크고 굵게 표시되어야 합니다.

    서술형¶

    4. 명함 뒷면을 '브랜드 각인'의 공간으로 설계해야 하는 이유를 2문장 이상으로 설명해 보세요.

    예시 답안 앞면은 개인의 연락처 등 실용 정보 전달에 집중하므로 브랜드 상징을 강조하기 어렵습니다. 뒷면을 브랜드 컬러와 로고로 채우면 명함을 뒤집거나 쌓아두었을 때도 브랜드가 시각적으로 각인되어, 손에 쥘 수 있는 가장 작은 포스터 역할을 하게 됩니다.

    자기점검 체크리스트¶

    • 명함 표준 규격(90×50mm)과 재단선·안전선 개념을 설명할 수 있다
    • Illustrator에서 도련 3mm가 포함된 아트보드를 설정할 수 있다
    • 기본시스템(로고·컬러·폰트)을 앞뒷면에 통일감 있게 적용했다
    • 정보 위계에 따라 폰트 크기를 차등 적용했다
    • 폰트 윤곽선 처리 후 인쇄용 PDF로 저장했다

    💭 성찰¶

    오늘 만든 명함을 짝과 교환하여 30초간 살펴본 후, 아래 질문에 답해 보세요.

    1. 이 명함을 보고 떠오르는 '브랜드의 인상'은 무엇인가요? (예: 차분함, 생동감, 신뢰감)
    2. 앞뒷면에서 통일감을 만드는 요소는 무엇이었나요?
    3. 내가 고친다면 어느 부분을 바꾸고 싶나요?

    좋은 명함은 말하지 않아도 브랜드를 느끼게 합니다. 여러분의 기본시스템이 명함 한 장에서 살아나는 순간을 경험해 보세요.
